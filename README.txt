PAY-PAY MEMORY GAME — V10

Regras:
- 3 segundos de memorizacao.
- 15 segundos para encontrar os 6 pares.
- Somente quem completa os 6 pares entra no ranking.
- Ranking Top 10 ordenado pelos menores tempos.
- Tempo registrado com precisao de milissegundos (performance.now()).
- Highscores salvos localmente no navegador via localStorage.
- Limpar os dados/cache deste site no navegador apaga o ranking local.

Para publicar: envie index.html, Style.css, script.js e a pasta Assets para o GitHub/Vercel.
